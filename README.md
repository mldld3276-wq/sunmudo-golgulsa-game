# 선무도 총본산 골굴사 · 고요 속의 한 수

골굴사의 선무도를 알리는 브라우저 미니게임입니다. 단일 HTML 파일로 만들었으며 PC와 모바일에서 플레이할 수 있습니다.

## 기능

- AI 대전 상대 6단계: 입문, 수련생, 숙련, 고수, 선객, 금강
- 대결 시작은 플레이어가 직접 누름
- 자동 수련을 켜면 시작 후 캐릭터가 자동으로 접근·공격·방어
- 손기술, 발기술, 회전차기, 회피, 도약, 호흡 기술별 쿨타임 표시
- 전투 중 회전차기, 회피, 점프, 가드, 호흡에 맞춘 다양한 만화풍 동작과 타격 효과
- 경기 결과로 염주알 보상
- 공격력·수비력·집중력·속도·민첩·쿨타임을 염주알로 강화
- 강화 단계 제한 없음. 다음 강화 비용은 단계에 따라 증가하고 능력 효과는 점차 완만해짐
- 하루 세 번, 세 번의 호흡을 따라가는 명상으로 무작위 능력치 1~3단 상승 (10% 확률로 5단 상승)
- 강화 총합에 따라 랭크 상승
- 기존 브라우저 프로필의 엽전 잔액을 염주알로 이어받음
- 브라우저에 저장하는 프로필과 기기 내 랭킹

## 조작

- 노트북: A/D 이동, W 도약, J 손기술, K 발기술, Q 회전차기, I 회피, L 막기, Space 호흡 집중
- 모바일: 화면 아래 터치 버튼
- 자동 수련: 자동 수련 버튼을 켠 뒤, **대결 시작**을 직접 누릅니다.

## 저장 및 랭킹 범위

프로필과 랭킹은 현재 브라우저의 localStorage에 저장됩니다. 같은 브라우저의 프로필끼리만 랭킹이 공유됩니다. IP 주소는 수집하지 않습니다. 모든 방문자가 공유하는 온라인 랭킹과 로그인은 서버/데이터베이스 연결이 필요합니다.
